My Linux setup changes over time, but the shape stays consistent: a fast terminal, a small set of reliable tools, and configuration that is easy to carry between machines.

## Priorities

- Keep daily commands memorable.
- Prefer tools that work well over SSH.
- Keep project notes next to the project.
- Avoid clever setup that is hard to reproduce later.

## Blog notes

This blog is part of that system. Markdown posts are easy to edit locally, review in git, and publish without opening a separate CMS.

When a setup detail becomes worth remembering, it can become a post.
